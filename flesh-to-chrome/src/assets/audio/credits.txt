# Áudio — Flesh to Chrome

## Estrutura
```
flesh-to-chrome/src/assets/audio/
  ambience/ # ambientes em loop por fase
  music/    # futuras BGMs por cena
  sfx/     # one-shots
  credits.txt
```

## Ambientes integrados

- `ambience/amb-sewer.mp3` — Fase 1/Esgoto;
- `ambience/amb-industrial.mp3` — Fase 2/Industrial;
- `ambience/amb-urban.mp3` — Fase 3/Meio Urbano;
- `ambience/amb-corporate.mp3` — Fase 4/Corporativo.

Esses arquivos ocupam temporariamente as chaves `bgm-phase-1` a `bgm-phase-4`
para aproveitar o controle de loop, pausa e troca de cena do `AudioManager`.
As demais chaves musicais continuam silenciosas.
