# Cyber Purp

Tileset importado de `cyber-purp.zip` para a Fase 5 (Topo).

- Imagem: `tileset.png`
- Grade: 32×32 px
- Dimensões: 512×1024 px
- Colunas: 16
- Total: 512 tiles
- Margem e espaçamento: 0 px

O `map.tmx` presente no pacote é apenas um mapa demonstrativo e não foi
copiado para o projeto. A definição usada pelo Tiled está em
`src/assets/maps/topo/tileset-topo.tsj`.

O arquivo ZIP não inclui autor, página de origem ou texto de licença. Esses
dados precisam ser confirmados antes da distribuição pública do jogo.
